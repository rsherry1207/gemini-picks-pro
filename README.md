# Gemini Picks Pro

An AI-powered sports analytics and betting platform that evaluates player prop bets, processes historical metrics, and dynamically calculates risk-adjusted payouts for custom user-defined wagers.

## Features
- **Custom Bet Analysis:** Allows users to input arbitrary wagers and uses AI to analyze risk and fair-value payout structures.
- **Data-Driven Insights:** Moves beyond surface-level box scores to evaluate deep player metrics and historical performance trends.
- **Supabase Backend:** Utilizes a secure database setup (`Bets Storage`) to track user wagers and historical data.

## Tech Stack
- **Backend & AI:** Python / API integration for predictive modeling and natural language bet processing
- **Database:** Supabase

## Getting Started
1. Clone the repository.
2. Configure your environment variables and database connections.
3. Run the application to begin generating data-driven betting insights.
